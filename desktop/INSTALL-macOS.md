# 10RemoteHub macOS 安装说明

> 发布包位于 [GitHub Releases](https://github.com/yizhixiaoheigou/10RemoteHub/releases)。先核对同一版本的 SHA256SUMS；源码开发环境见 [RELEASE.md](RELEASE.md)。

## 需要准备

- macOS 14 或更新版本。Apple 芯片选择 `-arm64` 的发布包。Intel 对应 `-x86_64`；由于没有 Intel Mac，本轮未做 Intel 真机测试，不承诺其硬件兼容性，仅在发布页确有对应包时使用。两种架构不能混用。
- 任一受支持的遥控器，两条路径按手里的设备自动分流：
  - **路径 A · 配套 `0416:0602` 2.4G 语音遥控器**：需随附 USB 接收器，并在安装组件与可选虚拟麦克风时输入管理员密码（支持全键表与遥控器麦克风收音）。
  - **路径 B · 通用 USB / 蓝牙 HID 遥控器**（键盘或媒体键报告）：无需安装读取组件和虚拟麦克风，只需授予系统**「输入监控」**与**「辅助功能」**权限后即可通过「添加遥控器」试按并导入照片学键。
- **能力边界**：系统可识别为标准 USB / 蓝牙 HID 键盘或媒体键的设备可直接接入。系统蓝牙读不了的 BLE 遥控器，App 提供外接 USB 蓝牙棒直连，但这条路在 macOS 上尚未实机验证（界面会标注「Mac 上这条路还在验证」）；厂商私有协议的设备停在「⚠️ 目前无法自动接入」，不承诺支持所有遥控器。

## 一、安装主程序

1. 打开下载的 `10RemoteHub-<版本>-<构建号>-arm64.dmg`（Intel 用 `-x86_64.dmg`），把 `10RemoteHub.app` 拖进「应用程序」。下载的是 zip 时，解压后同样拖进去。
2. 第一次双击时，系统会拦下来，提示「无法验证开发者」或「Apple 无法验证此 App 是否包含恶意软件」。这是预期行为：本软件使用项目自制的免费签名证书，没有向 Apple 付费购买开发者证书，也没有做公证。
3. 打开「系统设置 → 隐私与安全性」，向下滚动到「安全性」区域，会看到关于 10RemoteHub 的提示。点「仍要打开」，输入开机密码。
4. 再双击 `10RemoteHub.app`，在弹窗里点一次「打开」。以后正常启动不再需要这一步。

> 不同 macOS 版本按钮文字略有差别（「仍要打开」或「打开」）。如果系统设置里没看到提示，先双击一次应用让它出现。

## 二、跟着引导走

第一次打开会弹出引导面板（先「添加遥控器」，再按接收器类型完成权限或组件）：

1. **添加遥控器**：
   - 所有遥控器走同一流程：选中接收器或蓝牙遥控器，试按一次，App 会告诉你它属于哪一档（✅ 直接接入 / 🔧 点一下就能接入 / ⚠️ 目前无法自动接入 / ❓ 看不到设备）。之后点「导入照片，开始学习」：有麦克风的先在照片上点一下语音键的位置（会告诉你这只遥控器的麦克风能不能用），再逐个点按键位置并按实体键，保存即可。新遥控器默认按硬件 ID 命名，如「遥控器 0416:0602」；
   - 通用 USB / 蓝牙 HID 遥控器需在通用设置先授予 **「输入监控」** 后才能看到试按信号。
2. **完成权限与组件**（添加后自动进入这一步，按「还差几步」清单逐项完成，做完自动打勾）：
   - 通用 USB / 蓝牙遥控器：**只需授权「辅助功能」与「输入监控」**（不需要安装读取组件）。
   - 配套 `0416:0602`：点击安装**「读取组件」**（需管理员密码），并授权**「辅助功能」**。
3. **完成按键确认并去按键映射**：按任意已配置按键确认连接后，关闭引导开始设置动作。

引导只出现一次；以后想重看，菜单栏图标 →「重新运行新手引导…」。不走引导、直接在「我的遥控器」添加时，保存后同样会弹出「还差几步」清单；侧栏的「完成设置（还差 N 项）」按钮随时可以再打开它。

## 三、手动授权（可选）

- 启动后进入「通用设置 → 系统授权」，分别可点**「辅助功能」**或**「输入监控」**行的「前往授权」。系统设置会打开，同时主窗口自动最小化（避免挡住列表），并出现小引导面板方便把 10RemoteHub 图标拖入列表。
- **权限职责区分**：
  - **辅助功能**：所有遥控器均必需（发送模拟快捷键、鼠标操作、窗口切换与九键上屏）。
  - **输入监控**：仅通用 USB / 蓝牙 HID 遥控器日常监听及「添加遥控器」试按/学键必需；配套 `0416:0602` 在正常使用时通过特权后台读取组件直接读取接收器，不经输入监控（但在添加向导首次试按检测阶段若开启输入监控同样有助于探测通用设备）。
- 第一次使用虚拟麦克风收音时，系统会询问麦克风权限，点「允许」。

## 四、安装系统组件（仅 `0416:0602` / 遥控器麦克风需要）

- 仅 `USB 0416:0602` 配套接收器需要安装**统一读取组件**：进入「通用设置 → 遥控器与读取组件」→ 安装（输入管理员密码）。装好后状态变为「已连接」。普通 USB / 蓝牙遥控器无需安装此组件。
- 只用电脑麦克风时，不需要安装虚拟麦克风。
- 要用遥控器麦克风时，到「语音设置 → 虚拟麦克风」安装。安装过程会重启系统音频服务，声音和录音会中断一两秒，请先暂停通话或录音。安装器结束时会自动启用并检查，能在系统里看到「10RemoteHub Microphone」即装好。App 运行时装的，语音设置会显示「已安装，重新打开 App 后生效」，点「重新打开 App」即可（已在运行的程序拿不到音频服务重启后的新设备）。

## 五、选择麦克风

- 自动切换（默认）：识别软件里选「系统默认」或「跟随系统」。录音时自动切到虚拟麦克风，停止后恢复原来的设备。
- 固定使用虚拟麦克风：识别软件里直接选「10RemoteHub Microphone」。
- 两种方式都不会改动识别软件自己的设置，也不会一直录音。

## 六、更新到新版本

1. 从菜单栏图标退出旧版。
2. 用新版替换「应用程序」里的 `10RemoteHub.app`。
3. 打开新版。如果签名身份保持一致，权限通常可以沿用；更换签名身份或系统再次询问时，需要重新授权。
4. App 不会检查已装的读取组件和虚拟麦克风是不是最新版。版本日志写明组件有更新时（如 `0.3.0` 的读取组件），新版打开后手动重装一次：读取组件打开 `/Applications/10RemoteHub.app/Contents/Resources/components/RemoteHubDevice.pkg`，虚拟麦克风在「语音设置 → 虚拟麦克风」重新安装。

## 卸载

删应用不是卸载：把 `10RemoteHub.app` 拖进废纸篓，后台读取组件、虚拟麦克风和登录启动项仍留在系统里。

正确做法：点菜单栏的 10RemoteHub 图标 →「卸载 10RemoteHub…」，确认后应用会退出并打开卸载程序（需要管理员密码）。它会把主程序、读取组件、虚拟麦克风和登录启动项一起清掉，只保留你的配置（`~/Library/Application Support/RemoteHub`）。

## 常见问题

- **提示「已损坏，无法打开」**：不能只据此判断是隔离标记。先从正式发布来源重新下载，按该版本的校验值核对文件；仍失败时保留完整提示并反馈，不直接移除安全检查。详见 [排障指南](TROUBLESHOOTING.md)。
- **按键没有反应**：「通用设置 → 权限」确认辅助功能为已授权；确认接收器插好、「遥控器与读取组件」显示「已连接」。遥控器闲置很久后普通键失灵、按一下语音键又好了，见 [排障指南](TROUBLESHOOTING.md)。
- **系统设置的权限列表里出现两个 10RemoteHub**：删掉旧的那条（旧版签名残留），保留开关已打开的一条。
- **录音没有声音**：确认虚拟麦克风已安装、系统「声音 → 输入」里能看到「10RemoteHub Microphone」；自动切换模式下识别软件要选「系统默认」。

## 为什么会有安全提示

当前构建方式使用项目自制的「10RemoteHub」签名证书，未使用 Apple Developer ID，也未做公证。自签名不能单独证明发布者身份或软件安全；需要结合可信下载来源、发布校验值和签名校验判断。签名身份一致有助于沿用系统权限，但不能保证每次更新都无需重新授权。系统提示的区别和处理方式见 [Apple 官方说明](https://support.apple.com/en-au/102445)。
